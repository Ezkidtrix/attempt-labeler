# Attempt Labeler
A very simple geode mod that puts a label above the object that killed you. So, when you get back to that part you can have something to motivate to get further!

# How to edit labels
1. Close the game fully
2. Open the mods save file directory, open "saved.json".
3. Within the phrases array, to add a new one, add a comma after the last one and add the phrase in there (ex. ..., "new-label").
4. Save the file, and reopen the game! :)
