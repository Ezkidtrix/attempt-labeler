# Attempt Labeler
A very simple geode mod that puts a label above the object that killed you. So, when you get back to that part you can have something to motivate to get further!

# How to edit labels
Open the mods save file directory, open saved.json. Then, within the phrases array, to add a new one, add a comma after the last one and add the phrase in there (ex. ..., "new-label").
